The keys history view opens when you run `/keyf h`.
The keys history view closes when you run `/keyf h` again while it is open.
The keys history view closes when you click the close button.
The keys history view can be moved by dragging the window.
`/keyf h refresh` (or `/keyf h r`) refreshes the active mythic run roster to match the current group and removes leavers.
The Refresh button in the detail pane does the same roster sync.
The keys history event list shows each run as `Instance - Key Level` on the first line and `yy-mm-dd` on the second line.
The event selector list is compact relative to the detail pane.
Selecting a run shows the snapshotted other players for that run.
The keys history view never shows the local player character.
Each player row shows `Name - Realm` in class color, season mythic rating, and item level.
Each player row has Pass (ReadyCheck green check), Fail (ReadyCheck red X), and Neutral (yellow ~) marks.
Those mark colors are always visible; the selected mark also shows a gold selection ring.
Clicking a rating button sets that mark; clicking the active mark clears it back to no input.
When a run has more than 4 other players, each row shows a delete control to remove that player from the run.
Opening the keys history view does not close other keyf windows.
