Main keyf windows render above normal game UI.
Main keyf windows can be open at the same time.
Opening a main keyf window does not close other main keyf windows.
Showing a keyf window raises it in front of other keyf windows.
Clicking a keyf window raises it in front of other keyf windows.
Note panels can be open at the same time.
Opening a note panel does not close other note panels.
Pressing Escape closes one keyf window per key press.
Pressing Escape closes the innermost open keyf window first.
Pressing Escape closes the add note window before the player notes view.
Pressing Escape closes the player notes view before any main keyf window.
Pressing Escape closes main keyf windows only when no note panel is open.
