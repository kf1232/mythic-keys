The debug window opens when you run `/keyf d`.
The debug window closes when you run `/keyf d` again while it is open.
The debug window closes when you click the close button.
The debug window can be moved by dragging the window.
The debug window shows a Dump season config button.
The Dump season config button prints live season dungeon values to chat.
The debug window shows a Dump instance loot button.
The Dump instance loot button prints Encounter Journal loot tables to chat.
The debug window shows a Dump instance loot (debug) button.
The Dump instance loot (debug) button prints loot tables and spec-eligibility debug for items with no spec icons.
Opening the debug window does not close other keyf windows.
